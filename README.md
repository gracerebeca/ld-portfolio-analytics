# ld-portfolio-analytics
L&D Portfolio Demand, Capacity & Delivery Risk Analytics

Overview
---------
Built a synthetic HR/L&D analytics environment using PostgreSQL and SQL to simulate an enterprise Learning & Development reporting function.

Objectives
---------
- Analyze learning demand trends
- Measure consultant workload
- Identify delivery bottlenecks
- Assess project delivery risk
- Build an end-to-end ETL pipeline

Tech Stack
---------
- PostgreSQL
- DBeaver
- SQL
- GitHub

Data Model
---------
Business Units
Consultants
Learning Requests
Stage History
Stakeholder Feedback

Key Metrics
---------
- Cycle Time
- Capacity Utilization
- Backlog Aging
- Delivery Risk
- Stakeholder Satisfaction
